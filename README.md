## News HeadLines Scraper

### Basic news headline scraper that gets the headlines from websites like:
* New York Times 
* Ycombinator News  

### Technologies: 
 * Git 
 * BeautifulSoup4 
 * Python 
 * Pylint 

### To execute script 
```bash
python3 -m venv venv 

source venv/bin/activate 

pip install bs4 requests 
```
